# Smart Timetable SaaS

An AI-powered scheduling and timetable clash detection platform for educational institutions.

## Workspace layout

- `apps/web` — React and TypeScript client application.
- `apps/api` — Express and TypeScript REST API (added in the next backend milestone).
- `packages/shared` — Cross-application types and validation schemas.
- `docs` — Architecture, API, and deployment documentation.

## Current milestone

The monorepo foundation and React application scaffold are complete. Product UI, authentication, the API, and database are intentionally built in later, reviewed milestones.
